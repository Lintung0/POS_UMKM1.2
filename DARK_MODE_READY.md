## 🚀 Cara Menggunakan

### 1. Buka Aplikasi
```
http://localhost:3000
```

### 2. Login
```
Username: admin
Password: admin123
```

### 3. Cari Toggle Button
- Lihat **sidebar** di sebelah kiri
- Scroll ke **bawah**
- Cari button dengan icon **🌙 Bulan** (light mode) atau **☀️ Matahari** (dark mode)
- Button ada **tepat di atas** button "Keluar" (merah)

### 4. Klik untuk Toggle
- **Klik sekali** → Switch mode
- Light → Dark: Klik button "Mode Gelap"
- Dark → Light: Klik button "Mode Terang"

- Background: Putih
- Text: Hitam
- Cocok untuk: Siang hari, ruangan terang

### Dark Mode (Gelap)
- Background: Abu-abu gelap
- Text: Putih
- Cocok untuk: Malam hari, ruangan gelap
- Lebih nyaman untuk mata
