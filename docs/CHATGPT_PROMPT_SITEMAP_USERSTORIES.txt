PROMPT FOR CHATGPT - POS UMKM SITEMAP & USER STORIES
=====================================================

Saya memiliki sistem Point of Sale (POS) untuk UMKM yang sudah selesai dikembangkan. Tolong buatkan sitemap lengkap dan user stories yang komprehensif berdasarkan fitur-fitur yang ada.

## INFORMASI SISTEM POS UMKM

### Tech Stack:
- **Backend**: Go + Gin + GORM + SQLite
- **Frontend**: React + Vite + Tailwind CSS
- **Authentication**: JWT dengan role-based access (Admin & Kasir)

### Fitur Utama yang Sudah Diimplementasikan:

#### 1. AUTHENTICATION & AUTHORIZATION
- Login system dengan JWT tokens
- Role-based access: Admin dan Kasir
- Session management
- Logout functionality

#### 2. DASHBOARD & ANALYTICS
- Real-time sales summary
- Today's sales, profit, transaction count
- Monthly sales statistics
- Top selling products analysis
- Sales trend charts (last 30 days)
- Low stock alerts
- Quick stats overview

#### 3. PRODUCT MANAGEMENT (Admin Only)
- CRUD operations untuk produk
- Fields: name, category, selling_price, cost_price, stock, description, image
- Stock management dengan real-time updates
- Product categorization
- Profit calculation per product
- Bulk operations support

#### 4. RAW MATERIALS MANAGEMENT (Admin Only)
- CRUD operations untuk bahan baku
- Fields: name, unit, stock, min_stock, cost_per_unit, supplier
- Low stock monitoring dan alerts
- Unit management (gram, ml, kg, pieces, etc.)
- Supplier tracking

#### 5. RECIPE MANAGEMENT (Admin Only)
- Link bahan baku ke produk
- Set quantity per unit produk
- Multiple materials per product
- Production cost calculation otomatis
- Recipe composition management
- Material usage tracking

#### 6. TRANSACTION PROCESSING (Kasir & Admin)
- Point of sale interface
- Shopping cart functionality
- Multiple payment methods (Cash, Card, Transfer)
- Real-time stock reduction (produk + bahan baku)
- Cash management (received, change calculation)
- Transaction validation (stock availability, sufficient payment)
- Receipt generation dan printing
- Transaction history

#### 7. INVENTORY MANAGEMENT
- Real-time stock tracking
- Automatic stock reduction saat transaksi
- Material stock reduction berdasarkan resep
- Low stock alerts dan notifications
- Stock validation sebelum transaksi
- Inventory reports

#### 8. REPORTING & ANALYTICS
- Daily sales reports
- Monthly sales reports  
- Transaction history dengan filtering
- Top products analysis
- Profit tracking per transaction
- Sales trend analysis
- Export functionality (PDF)
- Custom date range reports

#### 9. PRODUCTION COST CALCULATION
- Automatic cost calculation berdasarkan resep
- Material cost tracking
- Profit margin analysis
- Cost breakdown per product
- Production planning support

#### 10. SETTINGS & CONFIGURATION
- Store profile management
- User profile settings
- System preferences
- Notification settings
- Security settings
- Backup & restore options

### User Roles & Permissions:

#### ADMIN (Full Access):
- Semua fitur dashboard dan analytics
- CRUD produk, bahan baku, resep
- Transaction processing
- Semua reports dan analytics
- Production cost calculation
- Settings dan configuration
- User management

#### KASIR (Limited Access):
- Dashboard view (read-only)
- Product catalog (read-only)
- Transaction processing (POS)
- Basic reports (daily transactions)
- Receipt printing
- Profile settings (own profile only)

### Database Schema:
- Users (authentication)
- Products (inventory)
- RawMaterials (bahan baku)
- Recipes (product-material relationships)
- Transactions (sales records)
- TransactionDetails (line items)

## YANG PERLU DIBUAT:

### 1. SITEMAP LENGKAP
Buatkan sitemap hierarkis yang mencakup:
- Semua halaman dan sub-halaman
- Navigation flow antar halaman
- Role-based access untuk setiap halaman
- URL structure yang SEO-friendly
- Responsive design considerations

### 2. USER STORIES KOMPREHENSIF
Buatkan user stories dalam format:
"As a [role], I want to [action] so that [benefit]"

Untuk setiap fitur, buat:
- Primary user stories (happy path)
- Edge cases dan error scenarios
- Acceptance criteria yang detail
- Priority level (Must Have, Should Have, Could Have)

### 3. USER JOURNEY MAPPING
- Admin workflow (setup → daily operations → reporting)
- Kasir workflow (login → transactions → end of day)
- Customer interaction points
- Error handling flows

### 4. WIREFRAME SUGGESTIONS
- Key screen layouts
- Navigation patterns
- Mobile responsiveness considerations
- UI/UX best practices untuk POS systems

6. **Future Enhancements** - Potential features untuk development selanjutnya
