# 🌙 Cara Menggunakan Dark Mode

## Lokasi Toggle Button
1. Login ke aplikasi
2. Lihat sidebar di sebelah kiri
3. Scroll ke bawah sidebar
4. Cari button dengan icon **Bulan** 🌙 (light mode) atau **Matahari** ☀️ (dark mode)
5. Button berada tepat di atas button "Keluar" (merah)

## Cara Toggle
- **Klik sekali** untuk switch mode
- Light → Dark: Klik button dengan icon Bulan
- Dark → Light: Klik button dengan icon Matahari

## Fitur
✅ Theme tersimpan otomatis (tidak perlu setting ulang setiap login)  
✅ Semua halaman support dark mode  
✅ Smooth transition (tidak kasar)  
✅ Print receipt tetap jelas (selalu light mode saat print)

## Tampilan

### Light Mode (Terang)
- Background putih
- Text hitam
- Cocok untuk ruangan terang

### Dark Mode (Gelap)
- Background abu-abu gelap
- Text putih
- Cocok untuk ruangan gelap / malam hari
- Lebih nyaman untuk mata

## Tips
💡 Gunakan dark mode di malam hari untuk mengurangi kelelahan mata  
💡 Gunakan light mode di siang hari untuk visibility maksimal  
💡 Theme akan tetap tersimpan meskipun logout atau tutup browser
