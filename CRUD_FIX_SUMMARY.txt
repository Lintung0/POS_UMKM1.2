   SEBELUM:
   ────────────────────────────────────────────────────────────────────
   if (error.response?.status === 401) {
       // Langsung redirect untuk SEMUA 401 error
       window.location.href = '/login';
   }
   
   MASALAH:
   - Error 401 bisa dari berbagai sebab
   - Bukan hanya token expired
   - Bisa jadi authorization error (bukan admin)
   - Bisa jadi constraint error dari database

   Interceptor yang lebih smart:
   
   SESUDAH:
   ────────────────────────────────────────────────────────────────────
   if (error.response?.status === 401) {
       // Cek apakah benar-benar token error
       const errorMsg = error.response?.data?.message || '';
       
       if (errorMsg.includes('token') || 
           errorMsg.includes('jwt') ||
           errorMsg.includes('expired')) {
           // Baru redirect jika token error
           window.location.href = '/login';
       }
       // Jika bukan token error, biarkan component handle
   }
